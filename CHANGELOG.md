# Changelog

## 2.0.1
- Updated JMdict and JmdictFurigana to the latest versions.

## 2.0.0
- Settings window with tabs: fields, definitions, part of speech, furigana, lookup, shortcuts.
- Conjugated words are looked up in their dictionary form (食べた → 食べる).
- Furigana in the input field are ignored (覚悟[かくご] → 覚悟).
- New output fields: part of speech and Input (Furigana).
- Choose Definition: one shared window for browser and reviewer, live preview, remembered choices.
- Populate Definitions runs in the background with progress and can be undone.
- Dictionary cache: fast background loading.
- Customizable keyboard shortcuts.
